1. No personal credit files in repo. `data/raw/` and `data/processed/` must stay empty of PII. .gitignore blocks *.csv with PII patterns; PRs checked.
2. No instructions to submit false/inaccurate disputes, re-age debts, abuse fraud alerts, or sell tradelines. Goodwill/pay-for-delete documented as *conditional, written-agreement-only, furnisher-optional*.
3. No legal/financial advice. Every public surface (README, paper, notebooks) carries disclaimer + NFCC (https://www.nfcc.org/) / FCAA referral.
4. Public data only: aggregates with source+date; Kaggle synthetic with license; CFPB/Fed via official downloads.
5. Copyright: paraphrase claims; do not paste book templates verbatim. Paper cites, does not reproduce.
6. If extending to human data: IRB + informed consent + minimization + secure storage required. This repo alone does not qualify as human-subjects approval.
